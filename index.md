## -- Adding a code example --

##### In Markdown Format (.md):
```md

```
##### In Javascript Format (.js):
```js
console.log("Hello, World!");
```
##### In C Format (.c):
```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```
